# paymaster-verifier
A formal verification of an ERC-4337 paymaster system built for Fold — a decentralised memory capturing app. The spec models the core safety property of gas sponsorship: no UserOperation should ever execute if the paymaster's deposit is insufficient. Written in TLA+, the TLC model checker exhaustively verifies this invariant across every possible ordering of validate, execute, and pause actions — something unit tests alone cannot guarantee.
